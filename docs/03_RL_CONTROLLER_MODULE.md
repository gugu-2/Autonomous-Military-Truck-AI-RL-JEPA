It serves as the primary motor control and tactical decision-making engine, responsible for mapping fused spatial-temporal latent representations into smooth, precise, and safe vehicle control commands ($\alpha$ steering angle, $a$ throttle, $b$ brake, plus military and long-haul truck extensions).

### 1.1 Why Model-Based RL (Not Model-Free RL)?

Traditional Model-Free Reinforcement Learning algorithms (such as PPO, SAC, or DQN) are fundamentally unsuited for real-world or production autonomous driving due to three major limitations:

1. **Extreme Sample Inefficiency**: Model-free algorithms require $10^7$ to $10^8$ interaction steps to converge on complex urban driving tasks. Model-Based RL (MBRL) learns an internal dynamics model of the environment, enabling policy optimization using simulated "imagined" rollouts, achieving equivalent performance in $10^5$ to $10^6$ steps (a **100x to 1000x gain in sample efficiency**).
2. **Latent Space Planning**: Instead of relying solely on immediate reactive policy mappings, MBRL evaluates long-horizon predictive trajectories internally before selecting physical actuation commands.
3. **Sim-to-Real Domain Generalization**: Model-free policies overfit to specific visual assets, lighting artifacts, and simulator physics engines. By operating entirely on compressed, invariant latent embeddings generated by the JEPA world model, MBRL decouples perception representation learning from policy control.

| Dimension | Model-Free RL (PPO / SAC) | **Model-Based RL (DreamerV3 in JEPA Latent)** |
| :--- | :--- | :--- |
| **Sample Efficiency** | Very Low ($10^7+$ steps required) | **Extremely High ($10^5$ steps required)** |
| **Training Execution** | Direct interaction with real/sim environment | **100% inside imagined latent rollouts** |
| **Safety during Training** | High crash frequency during exploration | **Zero real-world/physical simulator crashes** |
| **Domain Shift Robustness** | Fails under altered visual/lighting conditions | **Robust via JEPA invariant representation** |
| **Planning Horizon** | Implicit, reactive policy | **Explicit $H$-step imagined rollout evaluation** |

### 1.2 Why DreamerV3?

OMNIDRIVE selects **DreamerV3** (Hafner et al., 2023) as its foundational MBRL architecture. DreamerV3 introduces critical innovations over prior world-model algorithms:

* **Scale-Free Learning via Symlog Scaling**: Driving reward signals (e.g., small progress rewards vs. large collision penalties) span multiple orders of magnitude. DreamerV3 uses `symlog` transformations to normalize rewards, values, and reconstruction losses without task-specific hyperparameter tuning.
* **Categorical Discrete Latents**: Rather than continuous Gaussian representations which suffer from mode collapse or posterior vanishing, DreamerV3 uses a grid of categorical distributions for stochastic state representations.
* **Fixed Hyperparameter Suite**: DreamerV3 uses identical network configurations and loss scaling factors across diverse domains (from 2D locomotion to complex 3D driving environments), ensuring structural stability across standard robotaxis, heavy trucks, and military vehicles.

### 1.3 The Zero Real-World Crashes Principle

In conventional RL, the agent must experience thousands of collisions to learn that hitting an obstacle yields a negative reward. On physical hardware, a single crash is catastrophic.

In OMNIDRIVE's Layer 5 architecture:
1. The **JEPA Encoder ($f_\theta$)** and **RSSM World Model** absorb sensor dynamics passively from offline driving logs or safe simulator execution.
2. The **Actor Policy ($\pi_\phi$)** trains **100% inside the imagined rollouts** generated by the World Model.
3. If an imagined trajectory approaches a high-hazard latent region ($E(s_t) \ge 0.70$), the Critic penalizes the state *within imagination*.
4. Consequently, dangerous exploratory actions are evaluated and discarded in internal latent memory, guaranteeing **zero physical crashes during policy training**.

```
                           └────────────────────────────┬────────────────────────────┘

        │                                               │                                               │
        ▼                                               ▼                                               ▼
┌───────────────────────────────┐               ┌───────────────────────────────┐               ┌───────────────────────────────┐
│          WORLD MODEL          │               │         ACTOR NETWORK         │               │        CRITIC NETWORK         │
│  - Encoder e_θ                │               │  Policy π_φ(a_t | S_t)        │               │  Value V_ψ(S_t)               │
│  - RSSM Dynamics              │               │  Outputs Steering, Gas, Brake │               │  Predicts Expected Symlog     │
│  - Observation Decoder d_θ    │               │  Squashed Normal Distribution │               │  Return via 255 Discrete Bins │
│  - Reward Predictor r_θ       │               └───────────────────────────────┘               └───────────────────────────────┘
│  - Continue Predictor c_θ     │
└───────────────────────────────┘
```

### 2.1 Component Breakdown

#### World Model
The World Model learns the physical dynamics of the environment in latent space. It comprises:
* **Encoder ($e_\theta$)**: Maps fused JEPA spatial-temporal state $s_t \in \mathbb{R}^{512}$ and sensor features into initial embedding vector $x_t \in \mathbb{R}^{1024}$.
* **RSSM Dynamics**: Updates internal deterministic state $h_t$ and stochastic latent state $z_t$.
* **Observation/Hazard Decoder ($d_\theta$)**: Reconstructs spatial latent features and JEPA hazard energy map $\hat{E}(s_t)$ from combined state $S_t = [h_t; z_t]$.
* **Reward Predictor ($r_\theta$)**: Predicts scalar multi-objective reward $\hat{r}_t = r_\theta(S_t)$ using a two-hot categorical density estimator.
* **Continue Predictor ($c_\theta$)**: Predicts episode continuation discount factor $\hat{\gamma}_t = \sigma(\text{MLP}(S_t)) \in [0, 1]$, identifying episode termination or collision states.

#### Actor Network
The Actor represents the operational policy $\pi_\phi(a_t | S_t)$.
* **Input**: Combined RSSM + JEPA state $S_t = [h_t; \text{vec}(z_t); s_t] \in \mathbb{R}^{2048}$.
* **Output**: Continuous action distribution parameterized by mean $\mu_\phi(S_t)$ and standard deviation $\sigma_\phi(S_t)$.
* **Bounding**: Actions are passed through a `tanh` transformation to strictly enforce bounds $a_t \in [-1, 1]^K$.

#### Critic Network
The Critic estimates the long-term expected cumulative symlog-transformed return $V_\psi(S_t)$.
* **Input**: State tensor $S_t$.
* **Output**: Discrete probability distribution over 255 symlog-spaced bins spanning $[-20.0, +20.0]$.
* **Advantage**: Binned two-hot representation prevents gradient explosion caused by extreme reward spikes or severe penalties.

### 2.2 Architectural Evolution: DreamerV1 vs DreamerV2 vs DreamerV3

| Feature / Architecture | DreamerV1 (2019) | DreamerV2 (2021) | **DreamerV3 (2023 - OMNIDRIVE Layer 5)** |
| :--- | :--- | :--- | :--- |
| **Stochastic Latent Space** | Continuous Gaussian $\mathcal{N}(\mu, \Sigma)$ | Categorical ($32 \times 32$ discrete) | **Categorical ($32 \times 32$ discrete with Free Bits)** |
| **Value Estimation** | MSE Loss on scalar $V(s)$ | MSE Loss on scalar $V(s)$ | **Two-Hot Cross-Entropy over 255 Symlog Bins** |
| **Reward Normalization** | Manual clipping / scaling | Manual scaling | **Automatic Symlog Scaling ($\text{symlog}(x)$)** |
| **KL Divergence Loss** | Standard KL Penalty | KL Balancing ($\alpha = 0.8$) | **KL Balancing + Symlog Free Nats Regularization** |
| **Policy Optimization** | Dynamics Backprop | Dynamics Backprop + Reinforce | **Normalized $\lambda$-Return Reinforce + Dynamics Backprop** |
| **Hyperparameter Stability** | Sensitive to learning rates | Requires tuning per domain | **Universal Fixed Hyperparameters across all domains** |

## 3. RSSM — Recurrent State Space Model (`rssm.py`)

The Recurrent State Space Model (RSSM) forms the core sequence processor of Layer 5. It divides the latent memory into a deterministic recurrent component ($h_t$) and a stochastic latent component ($z_t$).

```
                         ┌──────────────────────────────────────────┐
                         │           RSSM LATENT STATE S_t          │
                         │                                          │
                         │  ┌────────────────────────────────────┐  │
                         │  │ Deterministic State: h_t ∈ ℝ⁵¹²    │  │
                         │  │ (Recurrent Memory via GRU Cell)    │  │
                         │  └────────────────────────────────────┘  │
                         │  ┌────────────────────────────────────┐  │
                         │  │ Stochastic State: z_t ∈ ℝ³²ˣ³²     │  │
                         │  │ (32 Categoricals w/ 32 Classes)    │  │
                         │  └────────────────────────────────────┘  │
                         └──────────────────────────────────────────┘
```

### 3.1 Mathematical Formulation

The latent state at step $t$ is defined as $S_t = (h_t, z_t)$.

1. **Deterministic Recurrent State Update**:
   $$h_t = \text{GRU}\left(h_{t-1}, z_{t-1}, a_{t-1}\right)$$
   where $h_t \in \mathbb{R}^{512}$, $a_{t-1}$ is the executed action vector, and $z_{t-1}$ is the flattened stochastic representation.

2. **Prior Distribution (Imagination Phase)**:
   Predicts the next stochastic state based *only* on internal recurrent memory (without seeing future observations):
   $$\hat{z}_t \sim p_\theta(z_t | h_t) = \text{Softmax}\left(\text{MLP}_{\text{prior}}(h_t)\right)$$
   where $z_t \in \mathbb{R}^{32 \times 32}$ represents 32 categorical distributions with 32 logits each.

3. **Posterior Distribution (Observation Filtering Phase)**:
   Refines the stochastic state prediction using the real incoming observation $s_t$ (from Layer 2 JEPA):
   $$z_t \sim q_\theta(z_t | h_t, s_t) = \text{Softmax}\left(\text{MLP}_{\text{post}}\left(h_t, \text{Encoder}(s_t)\right)\right)$$

4. **KL Balancing Loss**:
   To prevent posterior collapse while ensuring the prior can accurately predict future physics in imagination:
   $$\mathcal{L}_{\text{KL}}(\theta) = \alpha \cdot \text{KL}\left( \text{sg}[q_\theta(z_t | h_t, s_t)] \,||\, p_\theta(z_t | h_t) \right) + (1 - \alpha) \cdot \text{KL}\left( q_\theta(z_t | h_t, s_t) \,||\, \text{sg}[p_\theta(z_t | h_t)] \right)$$
   where $\alpha = 0.8$ is the KL balancing parameter, and $\text{sg}[\cdot]$ denotes the stop-gradient operator.

### 3.2 Integration with Layer 2 / Layer 3 JEPA Output ($s_t$)

The RSSM interacts directly with the JEPA output stream:

```
┌───────────────────────────────┐
│   LAYER 2: JEPA VI-T ENCODER  │
│   s_t ∈ ℝ⁵¹² (Spatial Latent) │
└───────────────┬───────────────┘
                │
                │ Observation Vector s_t
                ▼
┌───────────────────────────────┐         ┌───────────────────────────────┐
│     RSSM POSTERIOR q_θ        │────────►│  Combined Latent State S_t    │
│  Computes z_t from (h_t, s_t) │         │  S_t = [h_t; vec(z_t); s_t]   │
└───────────────────────────────┘         └───────────────┬───────────────┘
                ▲                                         │
                │ Prior z_t                               ▼
┌───────────────────────────────┐         ┌───────────────────────────────┐
│      RSSM PRIOR p_θ           │         │   LAYER 5 ACTOR & CRITIC      │
│  Predicts z_t from h_t        │         │   Evaluates Policy & Value    │
└───────────────────────────────┘         └───────────────────────────────┘
```

1. **Conditioning**: At timestep $t$, JEPA provides $s_t \in \mathbb{R}^{512}$, containing multi-camera ViT token features and BEV spatial maps.
2. **Filtering**: The posterior $q_\theta(z_t | h_t, s_t)$ fuses JEPA's visual-spatial representation with RSSM's temporal sequence context $h_t$.
3. **Imagination Trajectory**: During latent rollouts, the posterior is omitted; the RSSM steps forward autonomously using the prior $p_\theta(\hat{z}_\tau | h_\tau)$ for $\tau = t+1 \dots t+H$.

## 4. Actor-Critic Design (`actor_critic.py`)

### 4.1 Actor Network Architecture & Action Distribution

The Actor network $\pi_\phi(a_t | S_t)$ maps the 2048-dimensional combined latent tensor $S_t = [h_t; \text{vec}(z_t); s_t]$ to a continuous action distribution.

```
Combined State S_t (2048-dim)
       │
       ▼
┌─────────────────────────────┐
│ MLP (512 units, SwiGLU)     │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ MLP (512 units, SwiGLU)     │
└──────────────┬──────────────┘
               │
       ┌───────┴───────┐
       ▼               ▼
Mean Vector μ_ϕ   Std Vector σ_ϕ
       │               │
       └───────┬───────┘
               ▼
   Raw Action u ~ 𝒩(μ_ϕ, σ_ϕ²)
               │
               ▼
   Action a = tanh(u) ∈ [-1, 1]^K
```

* **Distribution Type**: Squashed Diagonal Gaussian Distribution.
* **Reparameterization Trick**: $u = \mu_\phi(S_t) + \sigma_\phi(S_t) \odot \epsilon$, where $\epsilon \sim \mathcal{N}(0, I)$.
* **Bounded Output**: $a_t = \tanh(u_t)$.
* **Log-Probability Correction**:
  $$\log \pi_\phi(a_t | S_t) = \log p(u_t | S_t) - \sum_{i=1}^K \log \left( 1 - \tanh^2(u_{t,i}) + \epsilon_{\text{num}} \right)$$

### 4.2 Critic Network & Two-Hot Value Representation

To eliminate hyperparameter instability caused by varying reward scales, DreamerV3 replaces scalar MSE regression with **Two-Hot Categorical Cross-Entropy**.

```
Real Value Scalar V ∈ ℝ
       │
       ▼
Symlog Transform: y = symlog(V) = sign(V) * ln(|V| + 1)
       │
       ▼
Discretization into 255 Bins: b_k ∈ [-20.0, +20.0]
       │
       ▼
Two-Hot Target Vector: P_target ∈ ℝ²⁵⁵ (Non-zero at 2 adjacent bins)
```

1. **Symlog Transformation**:
   $$\text{symlog}(x) = \text{sign}(x) \cdot \ln(|x| + 1)$$
   $$\text{symexp}(y) = \text{sign}(y) \cdot \left( \exp(|y|) - 1 \right)$$

2. **Bin Grid Definition**: 255 linearly spaced bins $b_1, b_2, \dots, b_{255}$ covering symlog range $[-20.0, +20.0]$.

3. **Two-Hot Encoding**: A scalar target $y = \text{symlog}(R^\lambda)$ falling between bins $b_k$ and $b_{k+1}$ is represented as:
   $$P_{\text{target}}(b_k) = \frac{b_{k+1} - y}{b_{k+1} - b_k}, \quad P_{\text{target}}(b_{k+1}) = \frac{y - b_k}{b_{k+1} - b_k}$$
   with all other bin probabilities set to 0.

4. **Value Reconstruction**:
   $$V_\psi(S_t) = \text{symexp}\left( \sum_{k=1}^{255} P_\psi(b_k | S_t) \cdot b_k \right)$$

### 4.3 Target Calculation & Symlog Loss Functions

#### $\lambda$-Return Calculation
The target return for imagined state $\hat{S}_\tau$ over horizon $H=15$ is computed recursively:
$$R_\tau^\lambda = \hat{r}_\tau + \hat{\gamma}_\tau \cdot \left( (1 - \lambda) V_\psi(\hat{S}_{\tau+1}) + \lambda R_{\tau+1}^\lambda \right), \quad R_H^\lambda = V_\psi(\hat{S}_H)$$
where $\lambda = 0.95$ and $\hat{\gamma}_\tau$ is the predicted continue discount.

#### Critic Loss Function
$$\mathcal{L}_{\text{critic}}(\psi) = -\frac{1}{H} \sum_{\tau=1}^{H} \sum_{k=1}^{255} P_{\text{target}}\left(b_k \Big| R_\tau^\lambda\right) \log P_\psi\left(b_k \Big| \hat{S}_\tau\right)$$

#### Actor Loss Function
The Actor is updated by propagating analytical gradients directly through the RSSM world model dynamics (Dynamics Backprop) combined with Reinforce entropy regularization:
$$\mathcal{L}_{\text{actor}}(\phi) = -\frac{1}{H} \sum_{\tau=1}^{H} \left( \text{Normalize}\left(R_\tau^\lambda - V_\psi(\hat{S}_\tau)\right) + \eta \cdot \mathcal{H}\left(\pi_\phi(\cdot | \hat{S}_\tau)\right) \right)$$
where $\text{Normalize}(\cdot)$ uses 5th to 95th percentile return scaling, and $\eta = 3 \cdot 10^{-4}$ scales policy entropy $\mathcal{H}$.

| :--- | :--- | :--- | :--- | :--- |

### 5.2 Extended Vehicle Variant Action Dimensions

#### Military Tactical Variant Extensions (`a[3..4]`)
* **Turret Azimuth Angle ($\theta_{\text{turret}}$)**: `a[3]` $\in [-1.0, +1.0] \implies \theta_{\text{turret}} \in [-180.0^\circ, +180.0^\circ]$.
* **Mission Tactical Halt Flag ($m_{\text{halt}}$)**: `a[4]` $\in [-1.0, +1.0] \implies m_{\text{halt}} = \mathbb{I}(a[4] > 0.5) \in \{0, 1\}$. When active, forces active vehicle holding brake and disengages throttle.

#### Long-Haul Semi-Truck Extensions (`a[3..4]`)
* **Trailer Pneumatic Brake Pressure ($b_{\text{trailer}}$)**: `a[3]` $\in [-1.0, +1.0] \implies b_{\text{trailer}} \in [0.0, 1.0]$. Controls independent rear trailer brake assembly to prevent jackknifing on slick downhills.
* **Engine Retarder / Jake Brake Level ($r_{\text{retarder}}$)**: `a[4]` $\in [-1.0, +1.0] \implies r_{\text{retarder}} \in \{0, 1, 2, 3\}$ discrete stages based on interval mapping.

## 6. Reward Function Design (`reward_function.py`)

The OMNIDRIVE RL Controller uses a **Multi-Objective Scaled Reward Function**. The total scalar reward $R_{\text{total}}(t)$ is a weighted sum of individual domain objectives:

$$R_{\text{total}}(t) = w_{\text{safe}} \, r_{\text{safety}}(t) + w_{\text{prog}} \, r_{\text{progress}}(t) + w_{\text{comf}} \, r_{\text{comfort}}(t) + w_{\text{traf}} \, r_{\text{traffic}}(t) + w_{\text{eff}} \, r_{\text{efficiency}}(t) + w_{\text{mil}} \, r_{\text{mission}}(t) + w_{\text{stl}} \, r_{\text{stealth}}(t)$$

```
                               ┌────────────────────────────────────────────────────────┐
                               │           MULTI-OBJECTIVE REWARD CALCULATOR            │
                               └───────────────────────────┬────────────────────────────┘
                                                           │
        ┌───────────────┬───────────────┬──────────────────┼──────────────────┬───────────────┬───────────────┐
        ▼               ▼               ▼                  ▼                  ▼               ▼               ▼
  r_safety        r_progress      r_comfort          r_traffic          r_efficiency    r_mission       r_stealth
(JEPA Hazard)   (Route Progress)(Jerk & Steer)    (Rules & Speed)      (Energy Usage) (Mil Checkpoint)(Acoustic/RCS)
```

### 6.1 Mathematical Formulation of Reward Terms

#### 1. Safety Reward ($r_{\text{safety}}$)
Penalizes proximity to obstacles and high latent hazard energy predicted by Layer 2/3 JEPA:
$$r_{\text{safety}}(t) = -\alpha_E \cdot \exp\left(\beta_E \cdot E(s_t)\right) - \lambda_{\text{coll}} \cdot \mathbb{I}\left(d_{\text{min}} < d_{\text{critical}}\right)$$
* $E(s_t) \in [0, 1]$: Fused hazard energy from JEPA representation.
* $d_{\text{min}}$: Distance to closest obstacle (meters).
* Parameters: $\alpha_E = 2.0$, $\beta_E = 3.0$, $\lambda_{\text{coll}} = 100.0$, $d_{\text{critical}} = 1.0\text{ m}$.

#### 2. Progress Reward ($r_{\text{progress}}$)
Encourages movement along the global route path while maintaining lane alignment:
$$r_{\text{progress}}(t) = v_{\text{vehicle}} \cdot \cos(\Delta \theta_{\text{waypoint}}) - \gamma_{\text{dev}} \cdot |d_{\text{center}}|$$
* $v_{\text{vehicle}}$: Longitudinal speed ($\text{m/s}$).
* $\Delta \theta_{\text{waypoint}}$: Heading angle deviation relative to current map path segment.
* $d_{\text{center}}$: Lateral offset from lane center line ($\text{meters}$).
* Parameter: $\gamma_{\text{dev}} = 1.5$.

#### 3. Driving Comfort Reward ($r_{\text{comfort}}$)
Penalizes harsh steering inputs, sudden acceleration changes (jerk), and high lateral acceleration:
$$r_{\text{comfort}}(t) = -\left( c_1 \cdot (\dot{\alpha}_t)^2 + c_2 \cdot a_{\text{lat}}^2 + c_3 \cdot (\ddot{a}_{\text{long}})^2 \right)$$
* $\dot{\alpha}_t = \frac{\alpha_t - \alpha_{t-1}}{\Delta t}$: Steering velocity ($^\circ/\text{s}$).
* $a_{\text{lat}} = \frac{v^2}{R_{\text{curve}}}$: Centripetal lateral acceleration ($\text{m/s}^2$).
* $\ddot{a}_{\text{long}}$: Longitudinal jerk ($\text{m/s}^3$).
* Coefficients: $c_1 = 0.05$, $c_2 = 0.4$, $c_3 = 0.2$.

#### 4. Traffic Law Compliance Reward ($r_{\text{traffic}}$)
Penalizes speed limit violations and red light infractions:
$$r_{\text{traffic}}(t) = -\kappa_v \cdot \max\left(0, \, v_{\text{vehicle}} - v_{\text{limit}}\right)^2 - \lambda_{\text{light}} \cdot \mathbb{I}(\text{red\_light\_infraction}) - \lambda_{\text{lane}} \cdot \mathbb{I}(\text{solid\_line\_crossing})$$
* Coefficients: $\kappa_v = 0.5$, $\lambda_{\text{light}} = 50.0$, $\lambda_{\text{lane}} = 10.0$.

#### 5. Energy Efficiency Reward ($r_{\text{efficiency}}$)
Discourages excessive pedal cycling and idling energy loss:
$$r_{\text{efficiency}}(t) = -\left( \epsilon_a \cdot a_t^2 + \epsilon_b \cdot b_t^2 + \epsilon_{\text{idle}} \cdot \mathbb{I}(v=0 \land a_t > 0) \right)$$
* Coefficients: $\epsilon_a = 0.1$, $\epsilon_b = 0.1$, $\epsilon_{\text{idle}} = 1.0$.

#### 6. Military Mission Bonus ($r_{\text{mission}}$) [Military Mode Only]
$$r_{\text{mission}}(t) = \mu_1 \cdot \frac{\Delta d_{\text{target}}}{\Delta t} + \mu_2 \cdot \mathbb{I}(\text{waypoint\_reached}) - \mu_3 \cdot \mathbb{I}(\text{out\_of\_operational\_zone})$$
* Coefficients: $\mu_1 = 3.0$, $\mu_2 = 25.0$, $\mu_3 = 100.0$.

#### 7. Military Stealth Bonus ($r_{\text{stealth}}$) [Military Mode Only]
Penalizes high RPM acoustic output and exposure on crests/open terrain:
$$r_{\text{stealth}}(t) = -\zeta_1 \cdot (v_{\text{engine\_rpm}})^2 - \zeta_2 \cdot \text{RCS}_{\text{exposure}} - \zeta_3 \cdot \text{Thermal}_{\text{vis}}$$
* Coefficients: $\zeta_1 = 0.02$, $\zeta_2 = 2.0$, $\zeta_3 = 1.5$.

### 6.2 Mode-Specific Reward Weight Matrix

| Objective Weight | Standard Robotaxi Mode | Long-Haul Semi-Truck Mode | Military Tactical Mode |
| :--- | :--- | :--- | :--- |

## 7. Training in Imagination (`imagination_trainer.py`)

The `ImaginationTrainer` optimizes the Actor and Critic networks entirely within latent trajectories generated by the RSSM World Model.

```
 ┌─────────────────────────┐
 │ Replay Buffer (Offline) │
 └────────────┬────────────┘
              │ Sample Sequence Batch B (Batch Size = 16, Seq Len = 50)
              ▼
 ┌─────────────────────────┐
 │    WORLD MODEL UPDATE   │ ◄── Update RSSM, Decoder, Reward & Continue Predictors
 └────────────┬────────────┘
              │ Extract Initial Latent States S_0 ~ q_θ(z_0 | h_0, s_0)
              ▼
 ┌─────────────────────────┐
 │   IMAGINATION ROLLOUT   │ ◄── Step Actor π_φ & RSSM Prior p_θ for H = 15 Horizon Steps
 └────────────┬────────────┘
              │ Imagined Sequence: {S_τ, a_τ, r_τ, γ_τ} for τ = 1...15
              ▼
 ┌─────────────────────────┐
 │  ACTOR-CRITIC UPDATE    │ ◄── Compute λ-Returns & Symlog Losses, Backprop Gradients
 └─────────────────────────┘
```

### 7.1 Detailed Training Loop Pseudocode

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class ImaginationTrainer:
    """
    Implements DreamerV3 training loop using imagined rollouts
    from the RSSM + JEPA latent world model.
    """
    def __init__(self, world_model, actor, critic, replay_buffer, config):
        self.wm = world_model
        self.actor = actor
        self.critic = critic
        self.buffer = replay_buffer
        self.cfg = config
        
        self.wm_opt = torch.optim.Adam(self.wm.parameters(), lr=config.lr_wm)
        self.actor_opt = torch.optim.Adam(self.actor.parameters(), lr=config.lr_actor)
        self.critic_opt = torch.optim.Adam(self.critic.parameters(), lr=config.lr_critic)

    def train_step(self):
        # -------------------------------------------------------------
        # Step 1: Sample Context Sequence Batch from Replay Buffer
        # -------------------------------------------------------------
        # obs_seq: [B, T, 512] JEPA latents; act_seq: [B, T, K]; rew_seq: [B, T]
        obs_seq, act_seq, rew_seq, cont_seq = self.buffer.sample(
            batch_size=self.cfg.batch_size, seq_len=self.cfg.seq_len
        )
        
        # -------------------------------------------------------------
        # Step 2: Update World Model on Sequence Data
        # -------------------------------------------------------------
        wm_loss, posterior_states = self.wm.compute_loss(obs_seq, act_seq, rew_seq, cont_seq)
        
        self.wm_opt.zero_grad()
        wm_loss.backward()
        nn.utils.clip_grad_norm_(self.wm.parameters(), self.cfg.grad_clip)
        self.wm_opt.step()

        # -------------------------------------------------------------
        # Step 3: Rollout Imagined Trajectories in Latent Space
        # -------------------------------------------------------------
        # Flatten batch and sequence dimensions for imagination starting points
        # start_states: [B * T, 2048]
        start_states = self.wm.flatten_states(posterior_states).detach()
        
        imag_states, imag_actions, imag_rewards, imag_continues = [], [], [], []
        curr_state = start_states

        for tau in range(self.cfg.imagination_horizon): # H = 15 steps
            # Sample action from policy
            action_dist = self.actor(curr_state)
            action = action_dist.rsample() # Reparameterized sampling
            
            # Predict next latent state using RSSM Prior p_θ(z_{τ+1} | h_{τ+1})
            next_state = self.wm.rssm_prior_step(curr_state, action)
            
            # Predict reward and continuation discount in latent space
            pred_reward = self.wm.predict_reward(next_state)
            pred_continue = self.wm.predict_continue(next_state)

            imag_states.append(next_state)
            imag_actions.append(action)
            imag_rewards.append(pred_reward)
            imag_continues.append(pred_continue)

            curr_state = next_state

        # Stack imagined sequences: Shape [H, B*T, ...]
        imag_states = torch.stack(imag_states, dim=0)
        imag_rewards = torch.stack(imag_rewards, dim=0)
        imag_continues = torch.stack(imag_continues, dim=0)

        # -------------------------------------------------------------
        # Step 4: Compute Value Estimates & λ-Returns
        # -------------------------------------------------------------
        with torch.no_grad():
            imag_values = self.critic.predict_value(imag_states) # [H, B*T]
            lambda_returns = self.compute_lambda_returns(
                imag_rewards, imag_values, imag_continues, self.cfg.discount, self.cfg.lambda_gae
            )

        # -------------------------------------------------------------
        # Step 5: Update Critic Network (Two-Hot Cross Entropy)
        # -------------------------------------------------------------
        critic_loss = self.critic.compute_symlog_loss(imag_states, lambda_returns)
        
        self.critic_opt.zero_grad()
        critic_loss.backward()
        nn.utils.clip_grad_norm_(self.critic.parameters(), self.cfg.grad_clip)
        self.critic_opt.step()

        # -------------------------------------------------------------
        # Step 6: Update Actor Network (Dynamics Backprop + Reinforce)
        # -------------------------------------------------------------
        # Normalize returns using 5th and 95th percentiles
        norm_returns = self.normalize_returns(lambda_returns)
        
        actor_entropy = self.actor(imag_states.detach()).entropy().mean()
        actor_loss = -torch.mean(norm_returns) - self.cfg.entropy_scale * actor_entropy

        self.actor_opt.zero_grad()
        actor_loss.backward()
        nn.utils.clip_grad_norm_(self.actor.parameters(), self.cfg.grad_clip)
        self.actor_opt.step()

        return {
            "loss/world_model": wm_loss.item(),
            "loss/critic": critic_loss.item(),
            "loss/actor": actor_loss.item(),
            "actor/entropy": actor_entropy.item()
        }

    def compute_lambda_returns(self, rewards, values, continues, discount, lambda_gae):
        """
        Computes TD(λ) returns across imagined horizon H.
        """
        H = rewards.shape[0]
        returns = torch.zeros_like(rewards)
        next_return = values[-1]

        for t in reversed(range(H - 1)):
            returns[t] = rewards[t] + continues[t] * discount * (
                (1.0 - lambda_gae) * values[t + 1] + lambda_gae * next_return
            )
            next_return = returns[t]

        returns[-1] = values[-1]
        return returns
```

## 10. Safety Interlock (`safety_interlock.py`)

The **Safety Interlock** acts as a hard deterministic verification layer between the RL Controller output and the Layer 7 Vehicle Actuator interface. If the RL Policy outputs an unsafe command or fails to react to an impending hazard, the Safety Interlock overrides the policy and commands autonomous emergency intervention.

```
RL Policy Output: (α_rl, a_rl, b_rl)
                 │
                 ▼
┌─────────────────────────────────────────────────┐
│                SAFETY INTERLOCK                 │
│                                                 │
│  [Rule 1] Hazard Energy E(s_t) ≥ 0.70?          │
│  [Rule 2] Time-To-Collision (TTC) < 1.2s?       │
│  [Rule 3] Steering Rate |dα/dt| > 120°/s?       │
│  [Rule 4] Stopping Distance Exceeded?           │
└────────────────────────┬────────────────────────┘
                         │
        ┌────────────────┴────────────────┐
        │ NO VIOLATION                    │ VIOLATION DETECTED
        ▼                                 ▼
Execute Policy Action         OVERRIDE: Hard AEB (b = 1.0, a = 0.0)
                              Clamp Steering Rate to 120°/s
```

### 10.1 Deterministic Override Rules

1. **Hazard Energy Override**:
   If JEPA predicts hazard energy $E(s_t) \ge 0.70$ along the vehicle path:
   $$\text{Override: } a = 0.0, \quad b = 1.0 \quad (\text{Full Emergency Braking})$$

2. **Time-To-Collision (TTC) Limit**:
   $$\text{TTC} = \frac{d_{\text{relative}}}{v_{\text{relative}}} < 1.2 \text{ seconds} \implies \text{Full AEB Intervention}$$

3. **Maximum Steering Angle Velocity Limit**:
   Prevents vehicle rollover caused by sharp steering inputs at high speed:
   $$|\dot{\alpha}_t| = \left| \frac{\alpha_t - \alpha_{t-1}}{\Delta t} \right| \le 120.0^\circ/\text{s}$$
   If exceeded, steering is clamped: $\alpha_t^{\text{clamped}} = \alpha_{t-1} + \text{sign}(\alpha_t - \alpha_{t-1}) \cdot (120.0^\circ/\text{s}) \cdot \Delta t$.

4. **Minimum Stopping Distance Enforcement**:
   Calculates minimum physical braking distance based on tire-road friction coefficient $\mu$:
   $$d_{\text{stopping}} = \frac{v_{\text{vehicle}}^2}{2 \cdot \mu \cdot g} + v_{\text{vehicle}} \cdot t_{\text{reaction}}$$
   If distance to obstacle $d_{\text{obstacle}} < d_{\text{stopping}} + 2.0\text{m}$, throttle is zeroed ($a = 0.0$) and progressive braking is applied.

## 12. Integration with JEPA

Layer 5 relies on direct tensor streaming from **Layer 2 (Spatial-Temporal JEPA Encoder)** and **Layer 3 (JEPA Latent Predictor)**.

```
┌───────────────────────────────────┐      ┌───────────────────────────────────┐
│     LAYER 2: JEPA ENCODER         │      │    LAYER 3: LATENT PREDICTOR      │
│  - Multi-Camera ViT Tokens        │      │  - Imagined Latents s_t+1..s_t+10 │
│  - Fused Feature s_t ∈ ℝ⁵¹²       │      │  - Hazard Energy Map E(s_t)       │
└─────────────────┬─────────────────┘      └─────────────────┬─────────────────┘
                  │                                          │
                  └────────────────────┬─────────────────────┘
                                       │
                                       ▼
┌──────────────────────────────────────────────────────────────────────────────────┐
│                   LAYER 5 RL CONTROLLER INPUT TENSOR BINDING                     │
│                                                                                  │
│  Input State Tensor: S_t = [ h_t (512)  ||  vec(z_t) (1024)  ||  s_t^JEPA (512) ]  │
│  Total Input Tensor Dimension: 2048-dim Vector                                   │
└──────────────────────────────────────────────────────────────────────────────────┘
```

1. **State Vector Composition**:
   At timestep $t$, Layer 5 constructs the combined state vector $S_t \in \mathbb{R}^{2048}$:
   $$S_t = \begin{bmatrix} h_t \in \mathbb{R}^{512} \\ \text{flatten}(z_t) \in \mathbb{R}^{1024} \\ s_t^{\text{JEPA}} \in \mathbb{R}^{512} \end{bmatrix}$$
2. **Hazard Energy Grounding**:
   The hazard energy map $E(s_t)$ generated by Layer 3 is fed into Layer 5's reward module to calculate $r_{\text{safety}}(t)$ and serves as the trigger signal for the Safety Interlock.

```python
"""
OMNIDRIVE Layer 5 API Interface Stubs
Path: src/rl_controller/api.py
"""

from typing import Dict, Tuple, Any, Optional
import torch
import numpy as np

class RSSMState:
    """Dataclass holding deterministic and stochastic state tensors."""
    def __init__(self, h: torch.Tensor, z: torch.Tensor, logits: torch.Tensor):
        self.h = h            # [B, 512]
        self.z = z            # [B, 32, 32]
        self.logits = logits  # [B, 32, 32]

    def combined(self, s_jepa: torch.Tensor) -> torch.Tensor:
        """Returns concatenated 2048-dim state vector."""
        z_flat = self.z.reshape(self.z.shape[0], -1) # [B, 1024]
        return torch.cat([self.h, z_flat, s_jepa], dim=-1) # [B, 2048]


class DrivingPolicy:
    """
    Inference-ready wrapper for the Actor policy network.
    Executes real-time forward passes on vehicle edge hardware.
    """
    def __init__(self, model_path: str, device: str = "cuda"):
        self.device = device
        self.actor_net = torch.jit.load(model_path).to(device)
        self.actor_net.eval()

    @torch.no_grad()
    def select_action(self, state_tensor: torch.Tensor, deterministic: bool = False) -> np.ndarray:
        """
        Maps combined latent state S_t to physical vehicle action.
        Returns: np.ndarray of shape [K] containing bounded control outputs.
        """
        action_dist = self.actor_net(state_tensor.to(self.device))
        action = action_dist.mean if deterministic else action_dist.sample()
        return action.cpu().numpy().squeeze(0)


class SafetyInterlock:
    """
    Deterministic safety override shield evaluating physical interlock constraints.
    """
    def __init__(self, max_steer_rate: float = 120.0, ttc_threshold: float = 1.2):
        self.max_steer_rate = max_steer_rate
        self.ttc_threshold = ttc_threshold
        self.prev_steer = 0.0

    def verify_and_override(
        self, 
        proposed_action: np.ndarray, 
        hazard_energy: float, 
        current_speed: float, 
        obstacle_distance: float,
        dt: float = 0.05
    ) -> Tuple[np.ndarray, bool]:
        """
        Evaluates proposed action against safety rules.
        Returns: (safe_action, interlock_triggered_flag)
        """
        steer, throttle, brake = proposed_action[0], proposed_action[1], proposed_action[2]
        interlock_triggered = False

        # Rule 1: Hazard Energy Emergency Override
        if hazard_energy >= 0.70:
            return np.array([steer, 0.0, 1.0]), True

        # Rule 2: Time-To-Collision (TTC) Check
        ttc = obstacle_distance / max(current_speed, 0.1)
        if ttc < self.ttc_threshold and current_speed > 1.0:
            return np.array([steer, 0.0, 1.0]), True

        # Rule 3: Steering Angle Rate Limitation
        steer_rate = abs(steer - self.prev_steer) / dt
        if steer_rate > self.max_steer_rate:
            max_delta = self.max_steer_rate * dt
            steer = self.prev_steer + np.sign(steer - self.prev_steer) * max_delta
            interlock_triggered = True

        self.prev_steer = steer
        safe_action = np.array([steer, max(0.0, throttle), max(0.0, brake)])
        return safe_action, interlock_triggered


class RewardCalculator:
    """
    Multi-objective reward evaluation engine.
    """
    def __init__(self, mode: str = "robotaxi"):
        self.mode = mode
        # Weight configurations
        self.weights = {
            "robotaxi": [1.0, 0.8, 0.5, 1.0, 0.3, 0.0, 0.0],
            "truck":     [1.5, 0.6, 0.8, 1.0, 0.7, 0.0, 0.0],
            "military":  [1.2, 1.0, 0.1, 0.1, 0.2, 1.5, 0.8]
        }[mode]

    def compute_reward(self, metrics: Dict[str, float]) -> float:
        """Computes scalar total reward from raw physical metrics dictionary."""
        r_safe = -2.0 * np.exp(3.0 * metrics["hazard_energy"])
        r_prog = metrics["speed"] * np.cos(metrics["heading_err"]) - 1.5 * abs(metrics["lane_offset"])
        r_comf = -(0.05 * (metrics["steer_vel"]**2) + 0.4 * (metrics["lat_acc"]**2))
        r_traf = -0.5 * (max(0.0, metrics["speed"] - metrics["speed_limit"])**2)
        r_eff  = -(0.1 * (metrics["throttle"]**2) + 0.1 * (metrics["brake"]**2))
        r_mil  = metrics.get("mission_progress", 0.0)
        r_stl  = -metrics.get("acoustic_rpm", 0.0)

        rewards = np.array([r_safe, r_prog, r_comf, r_traf, r_eff, r_mil, r_stl])
        return float(np.dot(self.weights, rewards))


class CurriculumScheduler:
    """
    Manages stage promotion and environment difficulty parameters.
    """
    def __init__(self, initial_stage: int = 1):
        self.current_stage = initial_stage
        self.stage_history = []

    def evaluate_promotion(self, episode_completion_rate: float, collision_rate: float) -> int:
        """Promotes stage if performance criteria are satisfied."""
        if self.current_stage == 1 and episode_completion_rate > 0.98:
            self.current_stage = 2
        elif self.current_stage == 2 and episode_completion_rate > 0.95:
            self.current_stage = 3
        elif self.current_stage == 3 and collision_rate < 0.01:
            self.current_stage = 4
        elif self.current_stage == 4 and collision_rate == 0.0:
            self.current_stage = 5
        elif self.current_stage == 5 and episode_completion_rate > 0.90:
            self.current_stage = 6
            
        return self.current_stage


class DreamerV3Agent:
    """
    Top-level Layer 5 Agent combining World Model, Actor, Critic, and Safety Interlock.
    """
    def __init__(self, config: Dict[str, Any]):
        self.cfg = config
        self.interlock = SafetyInterlock()
        self.reward_calc = RewardCalculator(mode=config.get("vehicle_mode", "robotaxi"))
        self.scheduler = CurriculumScheduler()

    def act(self, s_jepa: torch.Tensor, hazard_energy: float, speed: float, dist: float) -> np.ndarray:
        """Generates safe operational vehicle action."""
        # 1. Forward pass through policy
        # 2. Pass through Safety Interlock
        # 3. Return physical control command
        raw_action = np.array([0.1, 0.5, 0.0]) # Stub
        safe_action, _ = self.interlock.verify_and_override(raw_action, hazard_energy, speed, dist)
        return safe_action
```

```python
def test_symlog_invariance():
    """Verifies numerical stability of symlog and symexp inverse transformations."""
    def symlog(x):
        return torch.sign(x) * torch.log(torch.abs(x) + 1.0)
    
    def symexp(y):
        return torch.sign(y) * (torch.exp(torch.abs(y)) - 1.0)

    test_inputs = torch.tensor([-1000.0, -1.0, 0.0, 0.5, 100.0, 50000.0])
    reconstructed = symexp(symlog(test_inputs))

    assert torch.allclose(test_inputs, reconstructed, atol=1e-4), "Symexp(Symlog(x)) failed reconstruction!"
```
